# 售后退换货政策（待审核草案）

> **状态：草案，未发布。禁止作为对消费者生效的承诺，也不会被客服 Agent 检索。**
> 发布前须由业务负责人和适用地区的合规/法务人员确认方括号内容、适用范围及现行强制性规定。

## 1. 适用范围

本政策适用于通过【销售渠道/店铺名称】购买、配送至【适用国家或地区】的【商品范围】。具体售后权利以订单页面、商品页面、销售合同和适用的强制性法律规定为准；如本政策与强制性规定不一致，以强制性规定为准。

## 2. 退货申请期限

消费者可在商品签收后的【退货申请期限】内提交退货申请。期限起算方式、节假日顺延规则及特殊商品的期限，应按适用法律和销售渠道规则填写并在下单前清晰告知。

## 3. 非质量原因退货

在适用规则允许的范围内，消费者因不再需要、尺码不合适等非质量原因申请退货时，商品应保持【可接受的商品状态】。消费者为判断商品是否符合需求所进行的合理查验，不当然视为不符合退货条件；超出合理查验范围造成的损坏、污损或使用痕迹，按适用规定及个案事实处理。

鞋类商品可补充说明：请在清洁、干燥的室内试穿，并保持鞋底及鞋面完好。不得将“原包装完好”设置为违反强制性规定的绝对退货条件；确有必要的包装要求应在下单前明确说明。

## 4. 质量问题及错发、漏发

如商品存在质量问题，或发生错发、漏发等由商家或履约环节造成的问题，消费者可按适用规定申请退货、换货、维修、补发或其他救济。商家应依法承担相应责任和合理费用。客服需核实商品问题及订单情况，但不得以提交非必要个人信息作为处理前提。

## 5. 换货及更换尺码

消费者可在【换货申请期限】内申请更换【可换范围，例如尺码/颜色】。换货须满足适用规则中的商品状态要求，并以目标商品有库存为前提。无库存时，客服应向消费者说明可选方案，不得承诺无法确认的到货时间。

因商品质量问题或商家履约错误产生的换货，费用按适用规定由责任方承担。因个人选择变更产生的换货，运费及可能产生的差额为【经业务确认的规则】；该规则须在交易前清晰告知，且不得减损法定权利。

## 6. 退货运费

- 因商品质量问题、错发、漏发或其他依法应由商家承担责任的原因退货，退货运费及相关合理费用由【责任主体/处理方式】承担。
- 因个人原因申请退货的运费由【经业务确认的承担方】承担；如商家提供运费补贴、上门取件或其他便利服务，应写明适用条件和范围。
- 客服在无法确认退货原因、商品状态或适用地区时，应先向消费者澄清，不得仅凭默认规则确定费用承担方。

## 7. 不适用情形

仅可列明适用法律允许排除或限制退换的商品和情形，并须在交易前以显著方式告知。此处应填写【依法可排除的商品类别及依据】。不得把商家自行设定的限制扩大到法定权利之外。

## 8. 申请与处理流程

消费者通过【平台/客服入口】提交订单号、申请类型和必要说明。商家应在【受理时限】内反馈处理进度。经确认需要寄回商品的，客服提供有效寄回方式及地址；消费者应保留寄送凭证。商家收到退回商品后，在【退款处理时限】内按原支付路径或适用规定办理退款，并告知可能的到账时间。

如处理需要照片或其他材料，商家应说明用途、最小必要范围和安全提交渠道，不应要求消费者通过公开渠道发送身份证号、支付密码或完整银行卡信息。

## 9. 争议与联系

如消费者对处理结果有异议，可通过【升级处理渠道/联系方式】申请复核。记录和使用消费者信息应限于处理售后所必需的范围，并遵守适用的数据保护要求。
